# 알고리즘

그래프 알고리즘, 문자열 매칭, 계산 복잡도와 NP 관련 개념을 정리한 노트입니다.

## 목차

### Graph Algorithms

- [Minimum Spanning Tree](<Minimum Spanning Tree.md>)
  - Prim과 Kruskal 알고리즘을 중심으로 minimum spanning tree를 정리합니다.
- [Single Source shortest paths](<Single Source shortest paths.md>)
  - 하나의 시작 정점에서 모든 정점까지의 최단 경로 문제를 다룹니다.
- [All pairs shortest paths](<All pairs shortest paths.md>)
  - 모든 정점 쌍 사이의 최단 경로를 구하는 알고리즘을 정리합니다.
- [Transitive Closure](<Transitive Closure.md>)
  - 그래프에서 도달 가능성(reachability)을 계산하는 방법을 다룹니다.

### String Matching

- [Knuth-Morris-Pratt(KMP) algorithm](<Knuth-Morris-Pratt(KMP) algorithm.md>)
  - prefix function을 이용해 문자열 매칭을 효율적으로 수행하는 KMP 알고리즘을 정리합니다.
- [Boyer-Moore-Horspool alogrithm](<Boyer-Moore-Horspool alogrithm.md>)
  - skip table을 이용해 문자열 탐색을 빠르게 수행하는 Boyer-Moore-Horspool 알고리즘을 다룹니다.

### Complexity and NP

- [NP (1)](<NP (1).md>)
  - NP의 기본 정의와 polynomial time, verification 관점을 소개합니다.
- [NP (2)](<NP (2).md>)
  - NP-complete, NP-hard 등 계산 복잡도 이론의 확장 개념을 다룹니다.
