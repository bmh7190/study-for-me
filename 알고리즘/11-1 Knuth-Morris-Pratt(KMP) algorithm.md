일반적으로 문자열을 탐색한다고 하면 가장 먼저 떠올릴 수 있는 방법은 Brute-force 방식이다. 전체 문자열 `T` 위에 찾고자 하는 패턴 `P`를 올려두고, 패턴이 일치하지 않으면 패턴을 오른쪽으로 한 칸씩 이동시키면서 다시 비교하는 방식이다. 어느 위치에서 패턴의 모든 문자가 일치하면, 그 위치에서 패턴을 찾았다고 판단한다.

하지만 이 방식은 매우 단순한 만큼 비효율적이다. 불일치가 발생해도 항상 패턴을 한 칸만 이동하기 때문에, 이미 비교를 통해 얻은 정보를 제대로 활용하지 못한다.

조금만 다르게 생각해보면, 굳이 매번 한 칸씩만 이동할 필요는 없다. 비교 과정에서 일부 문자가 이미 일치했다면, 그 정보를 이용해 **다음에 다시 비교할 필요가 있는 위치로 바로 이동**할 수 있다.

예를 들어 전체 문자열이 `abdab`이고, 찾고자 하는 패턴이 `abc`라고 해보자. 처음부터 비교하면 `a`, `b`까지는 일치하지만, 마지막에서 `d`와 `c`가 달라 불일치가 발생한다. Brute-force 방식이라면 패턴을 한 칸만 이동시키겠지만, 이미 앞의 `ab`가 일치했다는 정보를 활용하면 더 효율적으로 이동할 수 있다.

# Pattern Analysis
문자열 탐색에서 매번 패턴을 한 칸씩 이동하면 비효율적이다. 이미 비교한 결과를 활용하지 못하고, 같은 부분을 반복해서 비교할 수 있기 때문이다.

그래서 KMP 알고리즘은 패턴을 단순히 한 칸씩 이동하는 대신, **이미 맞았던 부분은 최대한 유지하면서 이동할 수 있는 위치**를 찾는다. 이를 위해 KMP는 본격적인 탐색을 시작하기 전에 먼저 패턴 문자열 `P` 자체를 분석한다.

이때 사용하는 개념이 **prefix**와 **suffix**이다.

패턴의 각 부분 문자열에 대해, 그 문자열의 prefix와 suffix가 얼마나 겹치는지를 계산한다. 쉽게 말하면, 어떤 위치까지 문자가 일치하다가 실패했을 때, 패턴의 앞부분 중 어디까지를 다시 사용할 수 있는지 확인하는 과정이다.

---
예를 들어 다음과 같은 패턴이 있다고 하자.

$$  
P = abaaba  
$$

패턴의 인덱스는 다음과 같다.

$$
\begin{array}{c|cccccc}
\text{index} & 0 & 1 & 2 & 3 & 4 & 5 \\
\hline
P & a & b & a & a & b & a
\end{array}
$$

이제 각 위치 `k`까지의 부분 문자열 `P[0...k]`에 대해, prefix와 suffix가 일치하는 최대 길이를 구해보자.

#### k = 0

부분 문자열은 `a`이다.

이 경우에는 비교할 수 있는 proper prefix와 proper suffix가 없다. 자기 자신 전체를 prefix나 suffix로 사용하면 안 되기 때문이다.

따라서

$$  
F[0] = 0  
$$

---
#### k = 1

부분 문자열은 `ab`이다.

길이 1인 prefix는 `a`, suffix는 `b`이다. 서로 다르다.

따라서

$$  
F[1] = 0  
$$

---
#### k = 2

부분 문자열은 `aba`이다.

- 길이 1일 때 prefix는 `a`, suffix도 `a`이므로 일치한다.
- 길이 2일 때 prefix는 `ab`, suffix는 `ba`이므로 일치하지 않는다.

따라서 가장 길게 일치하는 길이는 1이다.

$$  
F[2] = 1  
$$

---
#### k = 3

부분 문자열은 `abaa`이다.

- 길이 1일 때 prefix는 `a`, suffix도 `a`이므로 일치한다.
- 길이 2일 때 prefix는 `ab`, suffix는 `aa`이므로 일치하지 않는다.
- 길이 3일 때 prefix는 `aba`, suffix는 `baa`이므로 일치하지 않는다.

따라서 가장 길게 일치하는 길이는 1이다.

$$  
F[3] = 1  
$$

---
#### k = 4

부분 문자열은 `abaab`이다.

- 길이 1일 때 prefix는 `a`, suffix는 `b`이므로 일치하지 않는다.
- 길이 2일 때 prefix는 `ab`, suffix도 `ab`이므로 일치한다.
- 길이 3일 때 prefix는 `aba`, suffix는 `aab`이므로 일치하지 않는다.
- 길이 4일 때 prefix는 `abaa`, suffix는 `baab`이므로 일치하지 않는다.

따라서 가장 길게 일치하는 길이는 2이다.

$$  
F[4] = 2  
$$

---
####  k = 5

부분 문자열은 `abaaba`이다.

- 길이 1일 때 prefix는 `a`, suffix도 `a`이므로 일치한다.
- 길이 2일 때 prefix는 `ab`, suffix는 `ba`이므로 일치하지 않는다.
- 길이 3일 때 prefix는 `aba`, suffix도 `aba`이므로 일치한다.
- 길이 4일 때 prefix는 `abaa`, suffix는 `aaba`이므로 일치하지 않는다.
- 길이 5일 때 prefix는 `abaab`, suffix는 `baaba`이므로 일치하지 않는다.

따라서 가장 길게 일치하는 길이는 3이다.

$$  
F[5] = 3  
$$

결과적으로 패턴 `abaaba`의 failure function은 다음과 같다.

$$
\begin{array}{c|cccccc}
k & 0 & 1 & 2 & 3 & 4 & 5 \\
\hline
P[k] & a & b & a & a & b & a \\
F[k] & 0 & 0 & 1 & 1 & 2 & 3
\end{array}
$$

---
# Failure Function

Failure function은 패턴 탐색 중 비교가 실패했을 때, **패턴을 어디까지 되돌려야 하는지 알려주는 함수**이다.

조금 더 정확히 말하면, 패턴의 `j`번째 문자에서 비교가 실패했다고 하자. 그러면 `j`번째 문자 직전까지는 이미 일치했다는 뜻이다.

즉,

$$  
P[0...j-1]  
$$

까지는 텍스트와 일치한 상태이다.

이때 KMP는 이 일치한 부분을 버리지 않는다. 대신 `P[0...j-1]` 안에서 prefix와 suffix가 일치하는 최대 길이를 찾고, 그만큼은 다시 비교하지 않고 유지한다.

그래서 실패한 위치가 `j`라면, 확인해야 하는 값은 보통

$$  
F[j-1]  
$$

이다.

예를 들어 패턴의 5번 인덱스에서 비교가 실패했다고 하자. 그러면 0번부터 4번 인덱스까지는 이미 일치한 것이다. 따라서 `F[4]`를 확인한다.

위 예시에서 $F[4] = 2$ 이다.

이 말은 `P[0...4] = abaab` 안에서, 앞부분과 뒷부분이 길이 2만큼 겹친다는 뜻이다. 실제로 prefix `ab`와 suffix `ab`가 일치한다.

따라서 KMP는 처음부터 다시 비교하지 않고, 이미 맞았던 suffix `ab`를 패턴의 prefix `ab`로 재사용한다. 쉽게 말하면, 패턴을 이동시키되 **이미 맞는 것으로 확인된 `ab`는 그대로 남겨두고**, 그 다음 위치부터 비교를 이어간다.

failure function의 핵심은 다음과 같다.

> 실패한 위치 바로 앞까지의 일치 정보를 이용해서, 패턴의 앞부분 중 다시 사용할 수 있는 최대 길이를 알려준다.

그래서 KMP는 불일치가 발생해도 텍스트 인덱스를 뒤로 되돌리지 않는다. 패턴 인덱스만 failure function 값을 이용해 이동시키면서 탐색을 계속한다.

---
# 의사코드 :  Knuth-Morris-Pratt(KMP) algorithm

```c
Algorithm KMPMatch(T, P)

F ← failureFunction(P)
i ← 0
j ← 0

while i < n
    if T[i] = P[j]
        if j = m - 1
            return i - j
        i ← i + 1
        j ← j + 1

    else if j > 0
        j ← F[j - 1]

    else
        i ← i + 1

return -1
```

여기서 `i`는 텍스트 `T`에서 현재 비교하고 있는 위치이고, `j`는 패턴 `P`에서 현재 비교하고 있는 위치이다.

먼저 `T[i]`와 `P[j]`가 같은 경우를 생각해보자. 이 경우에는 현재 문자가 일치했다는 뜻이다. 만약 이때 `j = m - 1`이라면 패턴의 마지막 문자까지 모두 일치한 것이다. 따라서 패턴이 텍스트 안에서 시작된 위치인 `i - j`를 반환한다.

만약 `j = m - 1`이 아니라면 아직 패턴에서 비교해야 할 문자가 남아 있다는 뜻이다. 그래서 `i`와 `j`를 각각 1씩 증가시켜 다음 문자 비교로 넘어간다.

반대로 `T[i]`와 `P[j]`가 다르면 불일치가 발생한 것이다. 이때 `j > 0`이라면 패턴의 앞부분은 어느 정도 일치한 상태에서 실패한 것이다. 따라서 처음부터 다시 비교하지 않고, failure function을 이용해서 `j`를 `F[j - 1]`로 이동시킨다.

예를 들어 `j = 5`에서 실패했다면, `j - 1 = 4`까지는 이미 일치한 상태이다. 그래서 `F[4]` 값을 확인하고, 그 값만큼 패턴의 앞부분을 재사용한다. 이렇게 하면 이미 맞았던 부분을 다시 비교하지 않아도 된다.

마지막으로 불일치가 발생했는데 `j = 0`인 경우가 있다. 이건 패턴의 첫 문자부터 틀렸다는 뜻이다. 즉, 지금까지 일치한 부분이 없으므로 재사용할 수 있는 정보도 없다. 따라서 텍스트 인덱스 `i`만 1 증가시켜서 다음 위치에서 다시 비교한다.

# 의사코드 : Failure Function Algorithm

```
Algorithm failureFunction(P)

F[0] ← 0
i ← 1
j ← 0

while i < m
    if P[i] = P[j]
        F[i] ← j + 1
        i ← i + 1
        j ← j + 1

    else if j > 0
        j ← F[j - 1]

    else
        F[i] ← 0
        i ← i + 1
```

`i`는 현재 failure function 값을 계산하려는 위치이고, j는 현재까지 prefix와 suffix가 몇 글자 일치했는지를 나타낸다.

먼저 `P[i]`와 `P[j]`를 비교한다.

만약 두 문자가 같으면, prefix와 suffix가 하나 더 길게 이어진다는 뜻이다.  
그래서 현재 위치의 failure function 값은 `j + 1`이 된다.

```
F[i] ← j + 1
i ← i + 1
j ← j + 1
```

즉, 문자가 일치하면 `F[i]`에 현재까지 일치한 길이인 `j + 1`을 저장하고, 그 다음 비교를 위해 `i`와 `j`를 둘 다 1씩 증가시킨다.

반대로 `P[i]`와 `P[j]`가 다르면, 현재 `j`만큼 일치했다고 생각했던 prefix를 그대로 사용할 수 없다는 뜻이다.  

이때 `j > 0`이면 `j`를 그냥 1 증가시키는 것이 아니라, $j ← F[j - 1]$ 로 이동시킨다.

이 말은 지금까지 맞았던 부분 안에서, 다시 사용할 수 있는 더 짧은 prefix 길이로 돌아간다는 뜻이다. 중요한 점은 이때 `i`는 증가하지 않는다는 것이다. 같은 `P[i]`를 더 짧은 prefix 후보와 다시 비교해야 하기 때문이다.

마지막으로 불일치가 발생했는데 `j = 0`이면, 첫 문자부터 맞지 않은 것이다. 이 경우에는 더 이상 되돌아갈 prefix도 없으므로

```
F[i] ← 0
i ← i + 1
```

로 처리한다.

# 시간 복잡도

## Failure Function Algorithm
`failureFunction(P)`는 패턴 문자열 `P`의 길이를 `m`이라고 할 때, 
전체 시간 복잡도가 $O(m)$ 이다.

Failure function을 계산할 때 `i`는 패턴을 왼쪽에서 오른쪽으로 한 번만 지나간다. 

- 문자가 일치하거나 `j = 0`에서 불일치하면 `i`가 증가한다. 
- 반대로 `j > 0`에서 불일치하면 `i`는 그대로 두고 `j`만 `F[j - 1]`로 뒤로 이동한다.

이때 `j`는 이전에 증가했던 만큼만 다시 감소할 수 있으므로 무한히 반복되지 않는다. 따라서 전체 반복 횟수는 최대 `2m`번 정도이고, 각 반복은 상수 시간에 처리되므로 failure function 계산의 시간 복잡도는 `O(m)`이다.

## Knuth-Morris-Pratt(KMP) algorithm
KMP 알고리즘은 탐색 과정에서 텍스트 인덱스 `i`를 뒤로 되돌리지 않는다. 

문자가 일치하면 `i`와 `j`를 함께 증가시키고, 불일치가 발생하면 `j`만 failure function을 이용해 뒤로 이동시킨다.  이때 `i`가 증가하지 않더라도 `j`가 감소하므로 `i - j`, 즉 패턴의 시작 위치는 증가한다. 

따라서 매 반복마다 `i` 또는 `i - j` 중 하나는 반드시 증가하고, 둘 다 최대 `n`번 정도만 증가할 수 있다. 그러므로 전체 반복 횟수는 최대 `2n`번이고, 각 반복은 상수 시간에 처리되므로 KMP 탐색의 시간 복잡도는 `O(n)`이다.
